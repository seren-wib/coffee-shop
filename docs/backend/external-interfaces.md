# 2.5 HW/SW/NW 외부 인터페이스 요구사항

커피 원두 쇼핑몰 시스템의 실행 환경과 외부 인터페이스 요구사항을 하드웨어(HW), 소프트웨어(SW), 네트워크(NW)로 구분하여 정의한다. 본 시스템은 수업 시연을 목적으로 로컬 PC에서 실행하며, 외부 서버에 배포하지 않는다.

## 2.5.1 하드웨어(HW) 인터페이스 요구사항

| 식별번호 | 요구사항 |
|---|---|
| HW-01 | 시스템은 Windows 또는 macOS가 설치된 로컬 PC에서 실행할 수 있어야 한다. |
| HW-02 | 프론트엔드와 백엔드는 수업 시연을 위한 로컬 환경에서 실행해야 하며, 외부 서버에 배포하지 않아야 한다. |
| HW-03 | 사용자는 PC에서 Chrome 브라우저를 통해 쇼핑몰에 접속하고 기능을 이용할 수 있어야 한다. |

## 2.5.2 소프트웨어(SW) 인터페이스 요구사항

| 식별번호 | 요구사항 |
|---|---|
| SW-01 | 프론트엔드는 React와 Vite를 사용하여 구현해야 한다. |
| SW-02 | 백엔드는 Python 3.12 환경에서 Django와 Django REST Framework를 사용하여 구현해야 한다. |
| SW-03 | 프론트엔드 실행 환경은 Node.js 20 LTS를 사용해야 한다. |
| SW-04 | 데이터베이스는 SQLite를 사용하며, 상품, 회원, 주문 등의 데이터를 관리해야 한다. |
| SW-05 | Windows와 macOS에서 동일한 절차로 시스템을 설치하고 실행할 수 있어야 한다. |
| SW-06 | 사용자 화면은 최신 버전의 Chrome 브라우저에서 정상적으로 동작해야 한다. |
| SW-07 | 프론트엔드의 API 요청은 하나의 공통 axios 인스턴스를 통해 처리해야 한다. |

## 2.5.3 네트워크(NW) 인터페이스 요구사항

| 식별번호 | 요구사항 |
|---|---|
| NW-01 | 프론트엔드와 백엔드는 REST API를 통해 통신해야 한다. |
| NW-02 | 프론트엔드와 백엔드 간 데이터는 JSON 형식으로 주고받아야 한다. |
| NW-03 | 회원 인증은 JWT(JSON Web Token) 방식을 사용해야 한다. |
| NW-04 | 로그인이 필요한 기능은 유효한 인증 토큰을 가진 사용자만 접근할 수 있어야 한다. |
| NW-05 | 액세스 토큰이 만료되면 리프레시 토큰을 이용하여 자동으로 재발급해야 한다. |
