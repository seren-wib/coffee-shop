# coffee-shop 설치 계획서 (SIP)

작성일 2026-11-19. 커피 원두 쇼핑몰 시스템을 운영 서버(EC2 한 대)에 처음 설치하고, 릴리스마다 배포하고, 거기서 동작을 확인하는 방법을 적는다. 차수는 나누지 않는다. 서버 주소, 도메인 이름, 운영자 계정, 키 값은 레포가 공개라 쓰지 않는다. 도메인은 "도메인"으로만 적는다(SDD 10절).
