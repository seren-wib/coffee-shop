## 6. 타당성 분석

- 기술: React, Django REST Framework, SQLite로 요구사항을 모두 만들 수 있다(NFR-19). 가장 큰 불확실성이던 SQLite 동시 주문은 스파이크로 확인했다(SDD 3.1절). 토스페이먼츠 승인·취소는 스파이크가 남아 있다(SDD 3.2절, 5.2절).
- 경제: 외부 비용은 운영 기간 동안 월 약 $15(추정)이고 나머지는 무료 요금제다(4.1절). 평가가 끝나면 AWS 자원을 지워 과금을 멈춘다.
- 법적: 결제는 테스트 모드뿐이라 실제 거래가 없다(SRS 7.1절). 이름, 이메일, 연락처, 주소를 저장하므로 개인정보 보호법의 안전성 확보 조치(비밀번호 일방향 암호화, 전송 구간 암호화, 접근 통제)를 따르고(SRS 1.4절), 가입 때 수집·이용 동의를 받고 처리방침을 공개한다(FR-58, FR-59). 평가가 끝나면 운영 DB와 백업을 지운다(SDD 8.7절).
- 운영: EC2 한 대에 웹 서버, 애플리케이션 서버, DB를 두고(NFR-20), 배포는 운영자가 스크립트 하나로 한다(SDD 10.4절). 재시작은 systemd, 백업은 하루 한 번 7개, 외부 감시는 5분마다다(SDD 10.5절).
- 일정: 2026-11-19부터 마감 2026-11-30 23:50까지 준비 → 기반 → 기능 병렬 → 통합·배포 네 단계로 짰다(3절). 예상 작업량은 추정이고 잰 값이 아니다.
