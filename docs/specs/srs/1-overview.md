## 1. 개요

### 1.1 목적

이 문서는 커피 원두를 온라인으로 판매하는 쇼핑몰 시스템이 해야 하는 일과 지켜야 하는 조건을 정의한다. 고객은 원두를 찾아보고 옵션을 골라 주문·결제하고 배송을 추적한다. 관리자는 원두와 재고, 주문, 배송, 취소를 처리한다. 시스템은 AWS EC2 인스턴스에 배포하고, Cloudflare에서 관리하는 도메인으로 인터넷에서 접속한다.

이 문서는 소프트웨어공학 팀 프로젝트의 요구사항 명세서이며, 설계 명세서(SDD)와 테스트 계획서(STP)가 이 문서의 ID를 근거로 쓴다.

### 1.2 이해관계자

| 역할 | 누구 | 관심사 |
| --- | --- | --- |
| 비회원 | 쇼핑몰에 처음 들어온 사람 | 로그인 없이 원두를 둘러보고 검색하기 |
| 회원 | 가입한 고객 | 원두 주문·결제, 배송 추적, 주문 취소, 내 정보와 배송지 관리 |
| 관리자 | 쇼핑몰 운영자 | 원두·옵션·재고 관리, 주문·배송·취소 처리 |
| 개발자 | 팀원 3명(프론트엔드, 백엔드 분담) | 요구사항을 설계·구현·테스트로 추적하기 |
| 운영자 | EC2 서버와 도메인을 관리하는 팀원 | 배포, 재시작, 시크릿 관리, 비용 |
| 평가자 | 담당 교수 | 요구사항 명세, 설계, 동작하는 코드의 완성도 |
| 결제대행사(PG) | 외부 시스템 | 결제 승인·취소 요청과 결과 통지 |
| 택배사 | 외부 시스템 | 송장번호로 배송 조회 |
| AWS | 외부 서비스 | 시스템이 도는 EC2 인스턴스 |
| Cloudflare | 외부 서비스 | 도메인의 DNS, 프록시, 브라우저 쪽 HTTPS 인증서 |

### 1.3 용어

- **원두**: 판매 단위가 되는 커피 상품. 원산지, 로스팅 정도, 맛 노트, 설명, 기본 가격을 가진다.
- **옵션**: 한 원두를 용량과 분쇄도 조합으로 나눈 판매 단위. 재고와 추가 금액을 가진다.
- **판매 상태**: 원두가 주문 가능한지 나타내는 값. 판매 중, 품절, 판매 중지 중 하나다.
- **장바구니**: 회원이 주문 전에 옵션과 수량을 모아두는 곳.
- **주문**: 회원이 한 번에 결제하는 옵션 묶음. 주문 항목 여러 개와 배송지 하나를 가진다.
- **주문 항목**: 주문 안의 옵션 한 줄. 주문 당시 원두 이름, 옵션, 단가, 수량을 저장한다.
- **상품 금액**: 주문 항목마다 (옵션 가격 × 수량)을 구해 더한 값.
- **최종 결제 금액**: 상품 금액에 배송비를 더한 값.
- **결제 기록**: 결제 시도 한 번의 결과. 한 주문에 여러 건 생길 수 있다.
- **취소 요청**: 결제 후 배송 전인 주문을 회원이 사유와 함께 취소해달라고 하는 것. 관리자가 승인하거나 반려한다.
- **송장번호**: 택배사가 발급한 배송 추적 번호.
- **액세스 토큰, 리프레시 토큰**: 로그인한 회원을 확인하는 JWT. 액세스 토큰이 만료되면 리프레시 토큰으로 새로 받는다.
- **EC2**: AWS의 가상 서버. 이 시스템의 운영 환경이다.
- **Cloudflare**: 이 시스템 도메인의 DNS를 관리하는 서비스.
- **운영 환경**: EC2에 배포되어 인터넷에서 접속하는 환경. 개발 환경은 개발자 PC다.

### 1.4 가정, 제약, 의존성

- 프론트엔드는 React(Vite), 백엔드는 Django와 Django REST Framework, 데이터베이스는 SQLite로 구현한다(NFR-19).
- 런타임은 Python 3.12, Node.js 24 LTS다. Node.js는 프론트엔드 빌드에만 쓰고, 운영 환경에서는 빌드 결과물(정적 파일)만 서비스한다.
- 운영 환경은 AWS EC2 인스턴스 한 대다. 웹 서버, 애플리케이션 서버, 데이터베이스 파일이 모두 이 인스턴스에 있다. 인스턴스 종류, 리전, 운영체제는 SDD 11절이다.
- 도메인은 Cloudflare에 등록된 영역(zone)에서 DNS를 관리하고, 브라우저는 HTTPS로만 접속한다. 도메인 이름은 문서에 적지 않는다(7.1절).
- 사용자는 최신 Chrome 브라우저로 접속한다(NFR-26).
- 결제는 외부 결제대행사(PG)를 통해 처리하며, 이번 학기에는 토스페이먼츠 테스트 모드만 쓴다. 실제 돈은 오가지 않는다(7.1절).
- 배송 추적은 택배사 조회 페이지로 연결하는 수준이며, 택배사 API와 직접 연동하지 않는다.
- 시스템은 개인정보(이름, 이메일, 연락처, 주소)를 저장하므로 개인정보 보호법의 안전성 확보 조치(비밀번호 일방향 암호화, 전송 구간 암호화, 접근 통제)를 따른다.
- 레포는 공개(public)다. 시크릿, 서버 주소, 관리자 계정 정보는 레포와 이 문서에 쓰지 않는다.
- 시연 데이터 규모는 원두 100종, 회원 50명, 주문 500건이다(NFR-3).
