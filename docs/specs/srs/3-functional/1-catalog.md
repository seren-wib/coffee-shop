### 3.1 원두 조회 (1차)

비회원과 회원 모두 쓸 수 있다. FR-2 ~ FR-5의 조건은 함께 쓸 수 있고, 함께 쓰면 모든 조건을 만족하는 원두만 나온다.

| ID | 요구사항 | 검증 |
| --- | --- | --- |
| FR-1 | 판매 중이거나 품절인 원두 목록을 한 페이지 20개씩 보여준다. 판매 중지된 원두는 고객에게 보이지 않는다. | `GET /api/products/` 200, `results` 20개 이하, 판매 중지 원두 없음. 품절 원두는 `sales_status=SOLD_OUT`으로 포함 |
| FR-2 | 원두를 이름의 일부로 검색한다. | `?search=에티` 요청에 이름에 "에티"가 든 원두만 반환 |
| FR-3 | 원두를 원산지로 거른다. | `?origin=에티오피아` 요청에 원산지가 에티오피아인 원두만 반환 |
| FR-4 | 원두를 가격 범위로 거른다. | `?min_price=10000&max_price=20000` 요청에 기본 가격이 그 범위인 원두만 반환 |
| FR-5 | 원두를 로스팅 정도로 거른다. | `?roast_level=LIGHT` 요청에 라이트 로스팅 원두만 반환 |
| FR-6 | 원두 상세에서 원산지, 로스팅 정도, 맛 노트, 설명과 옵션별 가격·품절 여부를 보여준다. | `GET /api/products/{id}/` 200, 옵션마다 `price`(기본 가격 + 추가 금액)와 `is_available` 포함. 판매 중지 원두는 404 |
