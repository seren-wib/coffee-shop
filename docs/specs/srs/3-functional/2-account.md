### 3.2 회원과 배송지 (1차)

| ID | 요구사항 | 검증 |
| --- | --- | --- |
| FR-7 | 비회원은 이메일, 비밀번호, 이름, 연락처로 회원가입한다. 이메일은 다른 회원과 겹칠 수 없고 비밀번호는 8자 이상이다. 가입한 계정의 권한은 항상 회원이다. 화면은 비밀번호 확인 칸으로 오타를 막는다. | `POST /api/auth/register/` 201, `role=MEMBER`(요청에 `role=ADMIN`을 넣어도). 겹치는 이메일 400, 7자 비밀번호 400. 확인 칸이 다르면 요청을 보내지 않음 |
| FR-8 | 회원은 이메일과 비밀번호로 로그인하고 액세스 토큰과 리프레시 토큰을 받는다. 이메일이 없을 때와 비밀번호가 틀릴 때 같은 응답을 준다. | `POST /api/auth/token/` 200, `access`·`refresh` 포함. 없는 이메일과 틀린 비밀번호 모두 401, 같은 본문 |
| FR-9 | 서버는 유효한 리프레시 토큰을 받으면 새 액세스 토큰을 발급한다. | `POST /api/auth/token/refresh/` 200, `access` 포함. 만료·위조 리프레시 토큰 401 |
| FR-10 | 액세스 토큰이 만료되어 요청이 401로 실패하면, 프론트엔드는 FR-9로 새 토큰을 받아 원래 요청을 한 번 다시 보낸다. 재발급도 실패하면 로그인 화면으로 보낸다. 로그인과 재발급 요청 자체의 401은 다시 보내지 않는다. | 만료 토큰 요청 401 → 재발급 → 재요청 200. 리프레시 만료 시 로그인 화면 표시. 로그인 401에 재발급 요청 0회 |
| FR-11 | 회원은 자기 이름, 이메일, 연락처를 조회한다. | `GET /api/me/` 200, 자기 정보만 |
| FR-12 | 회원은 자기 이름과 연락처를 고친다. 이메일은 바꿀 수 없다. | `PATCH /api/me/` 200 후 조회하면 바뀐 값. `email`은 바뀌지 않음 |
| FR-13 | 회원은 현재 비밀번호를 확인한 뒤 새 비밀번호(8자 이상)로 바꾼다. | `POST /api/me/password/` 204. 현재 비밀번호가 틀리면 400, 바꾼 뒤 옛 비밀번호 로그인 401 |
| FR-14 | 회원은 자기 배송지 목록을 기본 배송지가 먼저 오게 본다. | `GET /api/me/addresses/` 200, 자기 배송지만, 첫 항목 `is_default=true` |
| FR-15 | 회원은 배송지(받는 사람, 연락처, 우편번호, 주소, 상세 주소)를 등록한다. 처음 등록한 배송지는 기본 배송지가 된다(DR-16). | `POST /api/me/addresses/` 201, 첫 배송지 `is_default=true`. 필수 항목 비면 400 |
| FR-16 | 회원은 배송지를 고친다. | `PATCH /api/me/addresses/{id}/` 200. 다른 회원 배송지 404 |
| FR-17 | 회원은 배송지를 지운다. 기본 배송지 삭제는 DR-17을 따른다. | `DELETE /api/me/addresses/{id}/` 204. 배송지가 둘 이상일 때 기본 배송지 삭제 409 |
| FR-18 | 회원은 배송지 하나를 기본 배송지로 정한다. 기존 기본 배송지는 해제된다. | `POST /api/me/addresses/{id}/default/` 200 후 그 회원의 `is_default=true` 행이 하나 |
| FR-54 | 회원은 로그아웃한다. 프론트엔드는 저장한 액세스 토큰과 리프레시 토큰을 지운다. | 로그아웃 뒤 브라우저 저장소에 토큰 없음, 회원 전용 화면 접근 시 로그인 화면 |
| FR-58 | 비회원은 회원가입 화면에서 개인정보 수집·이용 안내(수집 항목, 목적, 보유 기간)를 보고 동의해야 가입할 수 있다. 서버는 동의한 시각을 저장한다. (2026-11-19 추가) | 가입 화면에 수집 항목·목적·보유 기간 표시. 동의 칸을 체크하지 않으면 요청을 보내지 않음. `POST /api/auth/register/`에 `privacy_agreed=true`가 없으면 400(`fields.privacy_agreed`), 있으면 201이고 `users.privacy_agreed_at`이 채워짐 |
