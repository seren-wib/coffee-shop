### 3.3 장바구니 (1차)

회원만 쓸 수 있다. 비회원이 담기를 누르면 로그인 화면으로 보낸다.

| ID | 요구사항 | 검증 |
| --- | --- | --- |
| FR-19 | 회원은 원두 상세에서 용량, 분쇄도, 수량을 골라 장바구니에 담는다. 같은 옵션이 있으면 수량을 더한다(DR-9). 품절·판매 중지 원두와 재고 0개 옵션은 담을 수 없다(DR-8). | `POST /api/cart/items/` 201(새 항목) 또는 200(수량 합침). 품절 옵션 409. 토큰 없이 401 |
| FR-20 | 회원은 장바구니에 담은 옵션, 수량, 현재 가격, 담을 수 있는지 여부와 상품 금액, 예상 배송비, 예상 결제 금액을 본다. 금액은 서버가 DR-14, DR-15로 계산해 내려준다. | `GET /api/cart/` 200, 항목마다 `price`·`is_available`, 상품 금액 = Σ(가격 × 수량), 29,000원이면 배송비 3,000원·30,000원이면 0원 |
| FR-21 | 회원은 장바구니 항목의 수량을 1개 이상, 남은 재고 이하로 바꾼다(DR-10). | `PATCH /api/cart/items/{id}/` 200. 0개 400, 재고 초과 409 |
| FR-22 | 회원은 장바구니 항목을 뺀다. | `DELETE /api/cart/items/{id}/` 204, 다시 조회하면 없음 |
