| ID | 요구사항 | 검증 |
| --- | --- | --- |
| FR-52 | 시스템은 서버와 데이터베이스가 응답하는지 알려주는 상태 확인 경로를 둔다. 인증 없이 부를 수 있고 내부 정보는 주지 않는다. | `GET /api/health/` 200, 본문 `{"status": "ok"}`. DB 연결이 끊기면 503 |
