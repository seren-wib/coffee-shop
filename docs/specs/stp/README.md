# coffee-shop 테스트 계획서 (STP)

작성일 2026-11-19. 커피 원두 쇼핑몰 시스템을 어떻게 시험하는지 정한다. SRS와 SDD처럼 이번 학기 범위 전체를 1차로 두고 차수는 나누지 않는다. 테스트 이름은 요구사항 ID로 시작하고, PR 본문도 그 ID를 적는다. 이 판은 구현 전에 필요한 1절(전략), 2절(단위), 3절(통합), 7절(CI)을 채웠다. 4절(화면)은 기능 단계에서 화면을 만들며, 5절(종단), 8절(리허설), 9절(인수)은 통합·배포 단계에서 채운다(SPMP 3절). 이 문서가 확정되면 구현으로 넘어간다.
